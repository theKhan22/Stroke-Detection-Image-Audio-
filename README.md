## Overview

Stroke is a leading cause of death and long-term disability worldwide. This project presents a multimodal deep learning framework for automated, interpretable stroke detection that integrates:

- **Visual features** — 228 2D facial landmarks extracted via MediaPipe Face Mesh, capturing unilateral facial drooping and asymmetry
- **Auditory features** — Mel-Frequency Cepstral Coefficients (MFCC) derived from speech recordings, capturing dysarthric speech patterns

A key innovation is the **epoch-wise stochastic modality masking** training strategy, which enables the model to learn robust unimodal and multimodal representations even when the two data sources lack patient-level correspondence.

### Key Results

| Modality | Accuracy | Precision | Recall | F1 Score | AUC |
|---|---|---|---|---|---|
| Facial landmarks + Audio MFCC | 95.33% | 93.31% | 97.67% | 95.44% | 0.980 |
| Facial landmarks only | 86.87% | 85.95% | 88.26% | 87.09% | 0.943 |
| Audio MFCC only | 97.41% | 96.61% | 98.28% | 97.44% | 0.988 |

## Architecture

The model consists of two parallel CNN–GRU branches — one for facial landmarks and one for MFCC features — which are fused via concatenation and passed through fully connected layers for binary stroke classification.

```
Facial Landmarks ──► Conv1D ──► BatchNorm ──► GRU(64) ──► BatchNorm ──► GRU(64) ──► Dropout(0.3) ──┐
                                                                                                      ├──► Concat ──► Dense(128) ──► Dropout(0.4) ──► Dense(64) ──► Dropout(0.4) ──► Sigmoid
Audio MFCC       ──► Conv1D ──► BatchNorm ──► GRU(64) ──► BatchNorm ──► GRU(64) ──► Dropout(0.3) ──┘
```

**Optimal hyperparameters** (from search over 128 configurations):
- Conv filters: 32, kernel size: 3
- GRU units: 64 (both layers)
- Dense layers: 128 → 64 neurons
- Dropout: 0.3 (recurrent), 0.4 (dense)
- Learning rate: 0.001
- Training epochs: 600

---

## Epoch-wise Stochastic Modality Masking

At each training epoch, a new mixed training batch is dynamically generated by splitting data into three subsets with a randomly sampled ratio `(a, b, c)` where `a + b + c = 1`:

- **Subset a** — Both modalities present (full multimodal input)
- **Subset b** — Facial landmarks only (audio MFCC zeroed out)
- **Subset c** — Audio MFCC only (facial landmarks zeroed out)

This forces the model to learn both unimodal and cross-modal representations, making it robust to missing or degraded inputs at inference time — a common occurrence in pre-hospital and resource-limited clinical settings.

Both datasets are publicly available on Kaggle:

| Modality | Dataset | Source | Size |
|---|---|---|---|
| Facial Images | [Stroke Facial Image Dataset](https://www.kaggle.com/datasets/thealif/stroke-facial-image-dataset) | Kaggle / Google Images | 1000 images (500 stroke, 500 non-stroke) → 2000 after augmentation |

## Usage

### 1. Preprocess Data

```bash
# Extract facial landmarks
python preprocessing/facial_landmarks.py --input data/facial/ --output data/processed/

# Extract MFCC features
python preprocessing/mfcc_extraction.py --input data/audio/ --output data/processed/
```

### 2. Feature Selection

```bash
python feature_selection/facial_selection.py
python feature_selection/audio_selection.py
```

This selects the top 116 facial landmarks and top 116 MFCC coefficients.

### 3. Train the Model

```bash
python training/train.py --epochs 600 --lr 0.001 --gru_units 64 --conv_filters 32
```

### 4. Evaluate

```bash
# Test all three modality conditions
python evaluation/evaluate.py --model_path checkpoints/best_model.h5
```

### 5. Robustness Testing

```bash
python robustness/facial_corruption.py
python robustness/audio_corruption.py
```

## Explainability (XAI)

Feature importance is computed by aggregating scores from three classifiers (Random Forest, XGBoost, CatBoost) over five randomized train–test splits. The top 10 diagnostically relevant facial regions identified are:

- **Cheeks** (right + left, 38 landmarks) — captures unilateral facial drooping
- **Lips** (upper/lower outer + inner, 44 landmarks) — reflects motor weakness and dysarthria
- **Eyebrows** (right + left upper, 17 landmarks) — helps distinguish central vs. peripheral facial palsy
- **Lower eyelids** (right + left, 18 landmarks) — additional motor nerve pathway indicators

These regions align directly with the clinical **FAST (Face-Arm-Speech-Time)** stroke assessment protocol.
